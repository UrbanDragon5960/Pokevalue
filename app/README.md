# PokeValue Android MVP

Build target: Android / Kotlin / Jetpack Compose.

Core flow: Scan card -> identify -> confirm -> value -> save -> collection.

Collection requirements:
- Persistent local storage
- Card image
- Card name/set/number/rarity
- Quantity and duplicate handling
- Estimated GBP value
- Collection total
- Search/filter/sort

This repository is the dedicated PokeValue project and is independent of Ultron/Lumen40.
